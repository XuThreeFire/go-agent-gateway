# 综合练习：课程学习助手

把基础网关扩展为查询虚构课程、解答计算问题的学习助手。不接入个人笔记、公司系统或真实学员资料。

## 要求

- 注册并启用 `CourseTool`，支持查询 `agent` 和 `sse`。
- 设置课程助手系统提示词，保留 `calc` 和 `now`。
- 工具收到未知主题时返回可修正错误。
- 页面可观察到工具步骤，并可取消、重新打开历史。
- 增加至少一个工具失败用例和一个完整回灌用例。

## 参考入口

工具完整实现位于 `backend/internal/tool/course.go`；如何注册见 `tools.md`。最小循环参考 `backend/cmd/agent-demo/main.go`，完整循环参考 `backend/internal/exec/executor.go`。

验收输入：`课程 agent`、`课程 unknown`、`计算 (8+2)*5`。前两条验证课程结果和业务错误，第三条验证旧能力仍然可用。模拟模式只演示规则匹配与数据流；若希望自然语言自主选择多个工具，再按第 03 章使用自己的真实模型。

交付应包含实现、正式测试与一段说明：新增能力在哪个模块，权限由哪里控制，数据如何回灌，取消与重试有哪些副作用风险。无需为了本练习引入向量数据库、消息队列或新的 Agent 框架。
