# 二次开发指南

目标是让你可以独立增加一个 Agent 能力，并通过正式测试证明它能工作。先完成基础教程的最小闭环与工具章节。

1. [新增一个工具](tools.md)：使用已有接口，完成参数校验、注册与配置。
2. [接入模型或新协议](models.md)：区分配置变化与协议适配。
3. [调整 Agent 行为](behavior.md)：修改系统提示词、历史策略和执行预算。
4. [扩展 HTTP/SSE 与页面](protocol.md)：保持生产、回放和前端契约一致。
5. [课程学习助手作业](exercise.md)：将以上能力组合成一个可验收的小项目。

开始前运行 `make test vet web-test web-build`。所有密钥、实验数据和本地配置留在忽略目录。公开教学说明更新在 `handbook/`，项目构建和协作不依赖 `docs/` 或 `.local-docs/`。
